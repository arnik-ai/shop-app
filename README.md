# Online shop Telegram Mini App (demo)

Single-page Mini App (plain HTML, no build). Opens inside Telegram from a bot's menu button.
Catalog with search, wishlist and a midnight flash deal; colors, sizes and live stock with "notify me";
cart with city-based shipping (courier day picked on a Shamsi calendar, or express post), 4-part installments,
order tracking with a tracking code, and a support page with instant answers.
Sample data only. PREVIEW = true: orders send nothing yet.
